# فرم ثبت درخواست کار — FRM-TPD-01

وب‌اپ تک‌صفحه‌ای فارسی (RTL) برای ثبت درخواست کار در دپارتمان فناوری و محصول (CPTO) همراه اول.
ویزارد ۶ مرحله‌ای (+ مرحلهٔ شرطی باگ) که در انتها یک سند رسمی PDF تولید می‌کند.

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی استاتیک در dist/ — قابل استقرار روی هر وب‌سرور داخلی
npm run preview  # پیش‌نمایش خروجی build
```

## نکته‌ها

- هیچ بک‌اند و هیچ ذخیره‌سازی‌ای وجود ندارد؛ state فقط در حافظهٔ session است.
- فونت وزیرمتن به‌صورت self-host در باندل قرار می‌گیرد (`@fontsource/vazirmatn`)، بنابراین
  خروجی build بدون اینترنت هم کار می‌کند.
- تبدیل تاریخ میلادی به شمسی بدون وابستگی خارجی در `src/lib/jalali.ts` پیاده شده است.
- فهرست افراد و محصولات در `src/data/people.ts` هاردکد شده؛ برای ویرایش فقط همین فایل را تغییر دهید.
- تولید PDF با CSS چاپ (`@media print` + `window.print()`) انجام می‌شود؛ قالب سند در
  `src/components/PrintDocument.tsx` است و پیش از چاپ، عنوان صفحه برای نام‌گذاری خودکار
  فایل PDF تغییر می‌کند.

## ساختار

- `src/components/Wizard.tsx` — ناوبری مراحل، نوار پیشرفت، اعتبارسنجی نرم، کلید Enter
- `src/components/steps/` — مراحل ویزارد (درخواست‌دهنده، نوع، شرح مسئله، معیارها، باگ، زمان‌بندی)
- `src/components/ReviewStep.tsx` — امتیاز آمادگی، کمبودها، پیش‌نمایش و دکمهٔ PDF
- `src/components/PrintDocument.tsx` — قالب سند رسمی چاپی (شامل بخش ۵ مخصوص مدیر برنامه)
- `src/lib/scoring.ts` — امتیاز آمادگی از ۱۰۰ با وزن‌های تعریف‌شده
- `src/lib/validate.ts` — اعتبارسنجی هر مرحله
- `src/state.ts` — reducer و ثابت‌های دامنه
